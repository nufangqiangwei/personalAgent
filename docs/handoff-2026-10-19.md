## 6. 环境与工具注意事项（踩过的坑）

1. **需要完全权限（full access）**：受限沙箱下 npm/Playwright 的管道子进程会 EPERM。
2. **PowerShell 为 5.1**，不是 pwsh 7。
3. **中文提交信息**：必须写入 UTF-8 文件后 `git commit -F .cache/msg-*.txt`；
   直接 `git commit -m "中文"` 会按 ANSI 传参导致提交信息双重编码。
4. **ruff --fix 写回失败**：部分由文件工具创建的 `src` 文件无法被子进程回写，
   表现为 `E902 拒绝访问`。处理方式：手工修正样式，或先
   `Copy-Item $f "$f.norm"; Remove-Item $f; Move-Item "$f.norm" $f` 再检查。
5. **E2E 浏览器**：Playwright 固定 revision 下载曾卡住；使用本机已有 Chromium：
   ```powershell
   $env:PERSONAL_AGENT_CHROMIUM_PATH = (Get-ChildItem "$env:LOCALAPPDATA\ms-playwright\chromium-*\chrome-win64\chrome.exe" | Sort-Object FullName -Descending | Select-Object -First 1).FullName
   powershell -NoProfile -ExecutionPolicy Bypass -File code/scripts/e2e.ps1
   ```
   E2E 使用隔离工作区 `.cache/e2e-data`，每次启动自动迁移+导入两份种子流程。
6. **依赖解释器**：一律 `uv run --project code/backend ...`（CPython 3.12.9）；
   禁止系统 Python 3.11.3。
7. **迁移**：当前 head 为 `0010`；生成新迁移前设置
   `PERSONAL_AGENT_DB_URL` 指向临时库，避免碰真实数据目录。
8. **真实模式**：`PERSONAL_AGENT_RUNTIME_ADOPTED` 未设为 1，`--mode live` 会拒绝启动；
   不得用 Mock 结果替代真实接入证据。
